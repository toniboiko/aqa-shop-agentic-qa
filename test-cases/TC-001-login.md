# TC-001-LOGIN

## Title

Login page UI validation

## Preconditions

- Application is available.
- User is not authenticated.

## Steps

1. Navigate to /login.
2. Verify that the login form is displayed.
3. Verify that the email field is visible.
4. Verify that the password field is visible.
5. Verify that the login button is visible.
6. Verify that the register button is visible.

## Expected Results

- Login form is displayed.
- Email input is visible.
- Password input is visible.
- Login button is visible.
- Register button is visible.

## Constraints

- Do not perform authentication.
- Use actual DOM elements.
- Do not invent selectors.
